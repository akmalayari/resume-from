# v0.3.1

## Summary

Refresh dependencies and release tooling, and publish matching core, Claude Code,
and Codex packages as `0.3.1`. Session-transfer commands and behavior are unchanged
from `v0.3.0`.

## Changes

- Update `gpt-tokenizer` to 4, keeping the `o200k_base` encoder used for GPT token budgets.
- Refresh Pi TUI, Vitest, lint tools, esbuild, and Node 24 type declarations; TypeScript 7
  builds while boundary tests keep TypeScript 6's compiler API.
- Update the SHA-pinned pnpm setup action to `v6.1.0`.
- Align plugin manifests and marketplace versions with the release, and document npm's
  publication-scanning delay.

## Upgrade

- Restart Pi after updating the package so the new extension loads.
- When upgrading from `0.2.0`, follow the [v0.3.0 migration steps](v0.3.0.md#upgrade)
  for programmatic APIs and obtain a fresh preview before confirming an import.
- A GitHub release can appear before npm finishes scanning its packages. If a pinned
  install returns `404`, check [package availability](../troubleshooting.md#a-new-release-is-not-available-on-npm)
  before retrying.
