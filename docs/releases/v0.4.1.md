# v0.4.1

## Changes

- Support Pi 1.x starting at 1.0.2, with a matching `pi-tui` development and peer dependency. Import, session loading, and out-of-context provenance checks run against Pi 1.0.2 in throwaway homes. Cross-agent conversion behavior is unchanged.

## Upgrade

Upgrade Pi to 1.0.2 or later in the 1.x line before updating the Pi extension.
Older Pi versions are outside the supported range. Restart Pi after updating.
Claude Code and Codex transfers do not require a Pi installation.
