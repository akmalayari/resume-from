# v0.3.0

## Summary

Continue Pi, Claude Code, and Codex conversations across linked Git worktrees without
losing the destination directory. Sessions from a main checkout or another worktree
are now discoverable from the checkout where you want to continue.

## Changes

- Match sessions by canonical Git common-directory identity across lists, row
  selections, session IDs, and file paths in the CLI and Pi extension, including
  alternate source profiles and checkout subdirectories. Independent clones,
  submodules, and nested repositories remain separate.
- Preserve recorded active-conversation directories. A surviving recorded path can
  identify a session whose original worktree was removed; conflicting repository
  identities are rejected with a diagnostic instead of guessed.
- Show the canonical destination in preview and bind confirmation and native session
  writes to it. Warn when a source directory differs: importing a conversation does
  not copy uncommitted changes, switch branches, or recreate worktrees.
- Honor cancellation through cached discovery and preview, and check it before
  landing. Preserve whitespace in Git paths and avoid duplicate destination lookups.
- Show Pi selection/import errors and distinguish skipped entries from whole profiles.
- Declare Pi's host-provided `pi-tui` as a peer dependency, preventing a separate
  runtime copy in Pi-managed installs.
- Update packaged instructions and user guides. Add real-worktree, confirmation,
  cancellation, and native-session readback regression coverage.

## Upgrade

- After updating the Pi package, restart Pi to load the new extension.
- Get a fresh preview before confirming an import after upgrading; old confirmation
  tokens are not compatible with the destination-bound preview.
- Before using the updated programmatic API, replace request `repoRoot` with
  `destinationCwd` in list/import requests. Callers using the old request shape must
  migrate; CLI and slash-command syntax is unchanged.
- Before running code with a custom `HostDeps.createRepo`, add
  `checkCancellation()`, use `distanceFrom(cwd, sourceCommit)`, and return `commonDir`
  and `isBare` from `identify()`. Older injected readers no longer satisfy the API.
